
==========================================
Reactの親コンポーネントと子コンポーネントの関係メモ
==========================================

このメモでは、Reactコンポーネントの親子関係と、
親から子へデータを渡して画面を表示する基本的な流れを説明します。
別のReactプロジェクトでも考え方を応用できるよう、基本の説明とこのプロジェクトの例をまとめます。

--------------------------------
1. コンポーネントとは
--------------------------------

コンポーネントは、画面を構成するUIの部品です。
例えば、画面全体、ヘッダー、メッセージ一覧、ボタンなどを
それぞれコンポーネントとして分けて作れます。

コンポーネントを分けると、役割ごとにコードを整理でき、
同じ部品を複数の場所で再利用しやすくなります。

--------------------------------
2. 親コンポーネントと子コンポーネント
--------------------------------

あるコンポーネントのJSX内で別のコンポーネントを使うと、
使う側が親コンポーネント、使われる側が子コンポーネントになります。

例えば、ChatContainerのJSX内にMessageListを書く場合は、
ChatContainerが親、MessageListが子です。

親コンポーネント:
  子コンポーネントを配置し、必要なデータを渡す側。

子コンポーネント:
  親から受け取ったデータを使い、自分の担当するUIを表示する側。

親子関係は、コンポーネントのファイルの場所や名前で決まるものではありません。
JSXでどのコンポーネントが別のコンポーネントを呼び出しているかで決まります。

--------------------------------
3. propsによる親から子へのデータ受け渡し
--------------------------------

親コンポーネントは、子コンポーネントをJSXに記述するとき、
属性のような形でデータを渡せます。
子コンポーネントは、そのデータをpropsとして受け取ります。

親コンポーネント:

<MessageList
  messages={messages}
  isStreaming={isLoading}
  streamingText={streamingText}
/>

この例では、messages、isLoading、streamingTextの値を
それぞれmessages、isStreaming、streamingTextというprop名でMessageListへ渡しています。

子コンポーネント:

interface MessageListProps {
  messages: Message[];
  isStreaming: boolean;
  streamingText: string;
}

export default function MessageList({
  messages,
  isStreaming,
  streamingText,
}: MessageListProps) {
  return (
    // propsの値を使って子コンポーネントのUIを作る
  );
}

TypeScriptでは、propsの型を定義すると、
子コンポーネントが受け取る値の種類を明確にできます。

--------------------------------
4. データの流れと画面表示
--------------------------------

基本的なデータの流れは、親から子への一方向です。

1. 親コンポーネントがstateやpropsなどから表示に必要な値を用意する。
2. 親コンポーネントが子コンポーネントをJSXに配置する。
3. 親が必要な値をpropsとして子に渡す。
4. 子が受け取ったpropsを使って、自分のJSXを描画する。
5. 子のJSXが親の画面の一部としてブラウザに表示される。

子コンポーネントの画面は、親コンポーネントとは別の画面に自動で表示されるわけではありません。
親のJSX内に子を配置しているため、子の表示は親が構成する画面の一部になります。

子は受け取ったpropsを直接書き換えず、表示に利用します。
表示内容を変える場合は、親が管理するstateを更新し、
更新後の値をpropsとして子へ渡す形が基本です。

------------------------------------------
5. このプロジェクトでのChatContainerとMessageList
------------------------------------------

src/components/Chat/ChatContainer/index.tsxのreturn内では、
MessageListを次のように配置しています。

<MessageList
  messages={messages}
  isStreaming={isLoading}
  streamingText={streamingText}
/>

このため、ChatContainerが親コンポーネント、
MessageListが子コンポーネントです。

ChatContainerが渡している値:

messages
保存済みのユーザー・AIメッセージ一覧です。

isLoadingをisStreamingとして渡した値
AIからの応答を待っているかどうかを表します。

streamingText
AIからストリーミングで受信している途中の文章です。

src/components/Chat/MessageList/index.tsxのMessageListは、
これらの値をpropsとして受け取ります。
messagesを順番に表示し、各メッセージのroleに応じて見た目を切り替えます。
また、isStreamingまたはstreamingTextの値に応じて、
受信中のAIのメッセージや入力中の表示を画面に追加します。

画面への流れ:

ChatContainerが値を管理・用意する
  ↓ propsとしてMessageListに渡す
MessageListがpropsを使ってメッセージ表示を組み立てる
  ↓
MessageListの表示がChatContainerの画面の一部として表示される

したがって、ChatContainerは「どのデータを表示するか」を渡し、
MessageListは「受け取ったデータをどのように表示するか」を担当しています。

--------------------------------
6. 子から親へ処理を伝える場合
--------------------------------

データは基本的に親から子へ渡しますが、
子で発生した操作を親に伝えたい場合は、親から関数をpropsとして渡します。
子はその関数を呼び出し、親に処理を依頼します。

親:

const handleChange = (value: string) => {
  setValue(value);
};

<Child onChange={handleChange} />

子:

<button onClick={() => onChange('更新値')}>
  更新
</button>

この形では、子が親のstateを直接変更するのではなく、
親から受け取った関数を呼び出し、親自身がstateを更新します。

--------------------------------
7. コンポーネントを分けるときの考え方
--------------------------------

1. 画面の中で独立した役割を見つける。
2. その役割のUIを子コンポーネントとして切り出す。
3. 子の表示に必要なデータを、親からpropsで渡す。
4. 子で起きた操作を親に反映する必要があれば、親から関数をpropsで渡す。
5. propsの型を定義し、子が必要とする値や関数を明確にする。

親には画面全体の状態や複数の子に関係する処理を置き、
子には担当するUIの表示や、その部品に限定した処理を置くと、
役割分担が分かりやすくなります。

----------------------------
8. 関連するファイル
----------------------------

src/components/Chat/ChatContainer/index.tsx
messages、isLoading、streamingTextを管理し、
MessageListを子コンポーネントとして配置して値を渡します。

src/components/Chat/MessageList/index.tsx
ChatContainerからpropsを受け取り、
保存済みメッセージやストリーミング中の文章を画面に表示します。

----------------------
全体の流れ（まとめ）
----------------------

親コンポーネントがデータを用意する
  ↓
子コンポーネントをJSXに配置し、propsを渡す
  ↓
子コンポーネントがpropsを使ってUIを描画する
  ↓
子のUIが親の画面の一部として表示される

親はデータや状態を管理し、子は受け取ったデータを表示するのが基本です。
子で起きた操作を親に伝える場合は、親から関数をpropsとして渡します。
