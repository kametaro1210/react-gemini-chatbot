==========================================
React Routerによるルーティング設定メモ
==========================================

このメモでは、react-router-domを使ってReactアプリ内のURLごとに画面を切り替える方法と、
このプロジェクトでルーティングに関係するファイルを説明します。

基本的に、以下のコマンドはpackage.jsonがあるReactアプリのフォルダで実行します。
このプロジェクトでは、react-gemini-chatbot\srcフォルダが該当します。

---------------------------------------------------
1. Reactアプリのフォルダへ移動する
---------------------------------------------------

実行するコマンド:

cd src

何をしているか:
Reactアプリのpackage.jsonがあるフォルダへ移動しています。

なぜ必要か:
npmコマンドは、基本的に現在いるフォルダのpackage.jsonを使ってライブラリを管理します。
別のフォルダで実行すると、意図したプロジェクトにインストールされないことがあります。

すでにReactアプリのフォルダにいる場合、このコマンドは不要です。

------------------------------------------------------------
2. react-router-domをインストールする
------------------------------------------------------------

実行するコマンド:

npm install react-router-dom

何をしているか:
ReactアプリでURLに応じた画面切り替えを行うためのライブラリをインストールしています。

インストールすると、package.jsonのdependenciesにreact-router-domが追加され、
node_modulesにもライブラリが保存されます。

このプロジェクトではすでにreact-router-domがdependenciesに含まれています。
そのため、通常はインストールをやり直す必要はありません。

別の人がこのプロジェクトを取得した場合、package.jsonをもとに依存ライブラリをまとめて入れるには、
Reactアプリのフォルダで次のコマンドを実行します:

npm install

-----------------------------------------
3. ルーティング用の部品を読み込む
-----------------------------------------

App.tsxで使用する主な部品:

BrowserRouter
Routes
Route

何をしているか:
BrowserRouterは、ブラウザのURLを使ったルーティングを有効にします。
Routesは、現在のURLに一致するRouteを探すための範囲です。
Routeは、URLと表示するReactコンポーネントを結び付けます。

これらを使うファイルの先頭で、react-router-domからimportします。

--------------------------------------
4. App.tsxでURLと画面を対応させる
--------------------------------------

このプロジェクトでは、src/App.tsxにルートを定義しています。

/signin
Signinコンポーネントを表示します。ログイン画面のURLです。

/signup
Signupコンポーネントを表示します。新規登録画面のURLです。

/
Chatコンポーネントを表示します。チャット画面全体の共通レイアウトです。

/の子ルート（index）
URLが/だけの場合、チャットをまだ選択していないことを案内する表示を出します。

/chats/:conversationId
ChatContainerコンポーネントを表示します。:conversationIdは固定文字列ではなく、
URLから会話IDを受け取るためのパラメーターです。
例えば/chats/123なら、conversationIdの値は123です。

----------------------------------
5. 親ルートと子ルートの関係
----------------------------------

Chatを親ルートにすると、チャット画面に共通するレイアウトを親側にまとめられます。
このプロジェクトのChatコンポーネントにはSidebarと<Outlet />があります。

<Outlet />は、現在一致している子ルートの画面を表示する場所です。
そのため、サイドバーを表示したまま、子ルートに応じて案内表示や会話画面を切り替えられます。

ルートの入れ子は、画面の部品が親子関係にあることを表します。
親のRouteにelementを指定しただけでは子画面は表示されず、親コンポーネント内に<Outlet />が必要です。

----------------------------
6. 関連するファイル
----------------------------

src/main.tsx
Reactアプリの起点です。Appコンポーネントを読み込み、HTML上のroot要素に表示します。
このプロジェクトではApp全体をBrowserRouterで囲むのではなく、App.tsx内で囲んでいます。

src/App.tsx
BrowserRouter、Routes、Routeを使い、URLと表示する画面の対応を定義します。
各画面のコンポーネントもここでimportします。

src/pages/Signin/index.tsx
ログイン画面です。App.tsxの/signinルートから表示されます。

src/pages/Signup/index.tsx
新規登録画面です。App.tsxの/signupルートから表示されます。

src/pages/Chat/index.tsx
チャット画面の親レイアウトです。SidebarとOutletを表示し、子ルートの画面を受け入れます。

src/components/Chat/ChatContainer/index.tsx
個別の会話画面です。App.tsxの/chats/:conversationIdルートから表示されます。

package.json
react-router-domなど、このReactアプリが使用するライブラリを管理します。

--------------------------------
7. ブラウザで表示を確認する
--------------------------------

Reactアプリのフォルダで開発サーバーを起動します:

npm run dev

ターミナルに表示されたURLをブラウザで開き、末尾に各パスを付けて確認します。

/signin
/signup
/
/chats/123

例えば開発サーバーのURLがhttp://localhost:5173の場合、
http://localhost:5173/signin のようにアクセスします。

サーバーを停止するには、ターミナルでCtrl+Cを押します。

----------------------
全体の流れ（まとめ）
----------------------

cd src
npm install react-router-dom
npm run dev

App.tsxでURLと画面を対応させ、親画面のChatにある<Outlet />へ子ルートを表示します。
